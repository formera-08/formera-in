# Formera Creations website

Static site: `index.html`, `privacy.html`, `404.html`, `css/styles.css`, `assets/`. No build step, nothing to install.

## Deploy on GitHub Pages

1. Put the contents of this folder at the **root** of your repository (so `index.html` is at the top level) and push.
2. Repository **Settings → Pages → Build and deployment**: Source *Deploy from a branch*, Branch `main`, folder `/ (root)`, Save.
3. The site goes live at `https://<user>.github.io/<repo>/` within a minute or two.

Before going live, replace `https://corridor-showcase.lovable.app` with your real address in `index.html`, `privacy.html`,
`robots.txt` and `sitemap.xml` (see `SEO-CHANGES.md`).

## Edit

Text and layout: edit the `.html` files directly. Colours and fonts: `css/styles.css`.
